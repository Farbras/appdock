# Ограничения интеграций

Проверка пакета означает успешный `winget show --id … --exact --source winget` на 28.10.2026. Она не означает, что каждый продукт был установлен на этом компьютере. Исходные ответы сохранены в `integration-checks.json`. Автоматические установки всех 40 продуктов намеренно не запускались при разработке.

| Группа | Реализовано | Требует участия / ограничение |
| --- | --- | --- |
| 40 продуктов WinGet | Точное разрешение источника, установка/обновление, обнаружение результата, хеш средствами WinGet | Сеть, UAC, ограничения лицензии и политики Windows могут остановить установщик |
| Отдельное скачивание | Для пакетов, где WinGet подтвердил offline distribution | Пакеты с неподтверждённой загрузкой отключены; процент/скорость/ETA не выдумываются |
| VS Code | 8 проверенных Marketplace ID, зависимости, текущий профиль, отдельные результаты | Неизвестные версии CLI или политики организации могут ограничить Marketplace |
| Python 3.12 | Зафиксирован официальный Windows-пакет 3.12.10; pip, PATH, user/machine | 3.12.16 — исходный релиз ветки, не традиционный Windows EXE. Настройка уже существующей установки не меняется при её пропуске |
| Visual Studio 2026 | Community/Professional/Enterprise, `.vsconfig`, includeRecommended/includeOptional, проверка компонентов через vswhere | Снимок Microsoft Installer 18.10.3. | WordCraft / GridCraft / DeckCraft / PhotoCraft | Отдельные записи семейства ArtCraft, официальные страницы getartcraft.com | Готовые установщики, подпись и параметры автоматизации отдельно не проверены; применяется ручной маршрут |

Размеры неизвестных пакетов остаются неизвестными. Предварительная проверка свободного места относится к системному диску; установщик рассчитывает конечный объём на выбранном томе. При отсутствии подтверждённого размера AppDock предупреждает об этом перед запуском.

В очереди нет фиктивных процентов, скорости или времени. Текущий адаптер предоставляет названия этапов и реальный журнал процесса. Обнаружение portable-приложений, полная проверка всех экземпляров БД и диагностика совместимости сторонних гипервизоров требуют отдельных специализированных адаптеров.
