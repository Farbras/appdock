## Исправления

- Демонстрационные загрузки изолированы от реального кэша и настройки папки на уровнях интерфейса, API и Rust. Реальное удаление файла требует подтверждения с именем и размером.
- Наборы сохраняют выбранное действие, включая скачивание Office 2024 и создание веб-ярлыка. Импорт, экспорт, карточки и план используют согласованные правила; дубликаты программ отклоняются до создания задач.
- Сравнение профиля согласовано со счётчиком и планом: отсутствие программы, обновление, закрепление и неизвестная версия обрабатываются явно. Неявное понижение версии запрещено.
- Очистка завершённого сохраняет ручные задачи и необходимые им зависимости. Массовые обновления учитывают неоднозначные экземпляры, пины, исключения и новые результаты сканирования.
- Компактный список показывает одну программу в строке. Панель выбора занимает выделенное место и не закрывает каталог. При 1366×768 видны поиск и полный первый ряд карточек.
- Исправлены контраст обеих тем, пустые состояния, русские подписи и числительные, клавиатурный фокус и ожидание Ctrl+K в UI-тесте. Увеличены малые элементы управления.
- Расширения VS Code выбираются явно; очистку выбора можно отменить; удаление набора подтверждается. В выборе видны версия, редакция и область установки.
- Демо показывает этапы, соответствующие действию. Долгие операции объясняют текущий этап без вымышленных процентов. Устаревшие асинхронные ответы не перезаписывают новый режим; частичные ошибки обнаружения показываются отдельно.
- История выводится страницами по 50 задач с сохранением полного отчёта. Компактный JSON сохраняется атомарно; каталог Rust разбирается один раз. На тестовых 5000 задачах открытие истории сократилось примерно с 1,6 с до 0,1 с. Результаты и границы замеров приведены в отчёте.
- Включены существовавшие изменения интеграций: прямое скачивание русского образа Office 2024 и использование проверенного Chrome EXE вместо изменяемого MSI-источника. Скачивание Office не является автоматической установкой или активацией; проверка хеша издателя образа не добавлялась.

## Проверка и ограничения

Перед выпуском выполняются проверки каталога, TypeScript/Vite, тесты TS/Rust, два набора UI-сценариев и сборка NSIS. Регрессии аудита добавлены в Windows CI. Материалы проверки упакованы отдельно от исходников; резервные рабочие копии и временные данные в публикацию не включаются.

Приложение рассчитано на Windows 11 x64 и требует WebView2. Установщик работает для текущего пользователя и может скачать WebView2 при его отсутствии. Сертификат подписи не настроен. Для реальных операций каталога нужен WinGet / App Installer и интернет; перед запуском требуется просмотр плана.

Настоящая проверка Windows DPI/WebView2, установщиков каталога, UAC, перезагрузки и полного сценария экранного диктора этим выпуском не подтверждается. UI проверяется в Edge с тестовыми ответами, обеими темами, четырьмя размерами окна и масштабированием; программы каталога ради проверки не устанавливаются. Подробные ограничения сохранены в [LIMITATIONS.md](LIMITATIONS.md).

Документ аудита и отчёт от 2 ноября фиксируют состояние на момент той проверки. В отличие от неё, выпуск 0.2.1 включает заново собранные нативный EXE и NSIS-установщик.
