## Что изменилось

- Под названием каждого набора отображаются мини-иконки входящих приложений. При наведении видно название программы; после редактирования состава иконки обновляются, а длинные ряды переносятся.
- Добавлены готовность компьютера, обновления, профиль ПК и просмотр полученных файлов.
- Очередь и история сохраняют отдельные запуски, исходные параметры и результаты. Повтор ошибок проходит новый подробный план и учитывает зависимости.
- Наборы можно создавать, редактировать, дублировать, импортировать и экспортировать. Доступна отмена последней замены выбора.
- Улучшены обнаружение установленных программ и редакций Visual Studio, диагностика, восстановление очереди и сообщения об ошибках хранения.
- Интерфейс разделён на компоненты; улучшены читаемость, клавиатурная навигация и работа при узком окне.

Полное описание поведения и ограничений: [AppDock 0.2.0](https://github.com/Farbras/appdock/blob/v0.2.0/docs/APPDOCK-0.2.0.md).

## Проверено перед выпуском

- Каталог: 80 продуктов, 40 WinGet-интеграций и 8 расширений.
- 27 тестов фронтенда, 25 модульных тестов Rust, проверка форматирования и production-сборка Windows x64.
- Сквозные сценарии интерфейса: план и демозапуск, повтор ошибок, ручное завершение, наборы, профиль ПК, смешанные загрузки, восстановление очереди, выбор обновлений, Ctrl+K, узкое окно и масштаб 125%.
- Мини-иконки готовых и пользовательских наборов: соответствие составу, обновление после редактирования, светлая тема и перенос длинных рядов.

Для интерфейса нужен Microsoft Edge WebView2 Runtime; установщик скачает его при отсутствии. Для установки программ из каталога нужны WinGet / App Installer и интернет. Node.js и Rust для запуска готовой версии не требуются. Сертификат подписи выпуска не настроен.

`SHA256SUMS.txt` содержит контрольные суммы готовых файлов. Архив `AppDock-0.2.0-source.zip` содержит исходный код.
