В «Офлайн-наборе» исправлен пустой список программ: Python, Git и VS Code можно выбирать прямо в разделе. Добавлены поиск, массовый выбор и причины недоступности остальных пакетов.

В выпуск также вошли проверка готовности программ и понятные ошибки, перенос безопасных настроек с резервными копиями, восстановление прямых загрузок, пауза / продолжение / отмена, трей и расписание проверки обновлений.

### Готовая версия для Windows x64

- **AppDock_0.2.3_x64-setup.exe** — установщик.
- **AppDock.exe** — приложение для запуска без установки.
- **AppDock-0.2.3-windows-x64.zip** — архив с приложением и инструкцией.
- **AppDock-0.2.3-source.zip** — исходный код.
- **SHA256SUMS.txt** — контрольные суммы файлов.

Автономные снимки: Python 3.12.10, Git 2.49.0 и VS Code 1.99.3, Windows x64. Остальные программы не включаются в полностью автономный набор без подтверждённых установщиков и зависимостей. Production-источник подписанного обновления каталога пока не настроен; встроенный каталог доступен.

Для запуска нужны Windows 11 x64 и WebView2. Установка программ запускается после просмотра и подтверждения плана. Подпись EXE сертификатом не настроена.

[Подробности выпуска и проверки](https://github.com/Farbras/appdock/blob/v0.2.3/docs/APPDOCK-0.2.3.md).
