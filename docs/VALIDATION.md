Файл SQLite имеет SHA-256 `f46ee2475de4cbe287e6e5f7d43c838796b14e7379cd216bdbb28d391429f9fc`, соответствующий манифесту WinGet. Файлы тестового скачивания находятся в локальной папке данных AppDock, а не в каталоге установленных программ.

Повторная проверка скачивания: Chrome EXE — 525 470 120 байт, SHA-256 `8783e3a9a3bb263a6b39da9e9ea6bdb7f31bb9dc9806f9b438ae7c1dde0480b0`; VS Code — 251 813 440 байт, SHA-256 `9b9e7305bc5f2d9176dff8263ba146fc7b0d65ce1fb499271fd7746ec53d66ed`. Оба значения совпали с манифестами WinGet. Номер VS Code 1.142.0 относится к пакету WinGet; его манифест сейчас ссылается на файл `VSCodeUserSetup-x64-1.141.2.exe`. Файлы этой проверки сохранены в `artifacts/winget-recovery-check/`. Ошибка `upgrade` → `install` проверена сценариями с подставленными кодами завершения, без реального запуска установщиков.

Скриншоты и локальные отчёты тестов сохранены в `artifacts/`. Демоочередь хранится отдельно от рабочей. После проверки нативное окно оставлено в явном деморежиме для просмотра.

Полная установка всех программ каталога, платная активация и установка полного профиля Visual Studio не выполнялись на пользовательском компьютере. Состояния отказа UAC, потери сети и нехватки места обработаны в ядре, но не все эти сбои воспроизводились физически. Полная таблица ограничений находится в `LIMITATIONS.md`.

Для сборки использованы извлечённые в `.tools` официальные архивы компилятора и Windows SDK. Системная установка инструментов C++ не выполнялась; её запрос UAC был отменён. Архивы компилятора сверены с SHA-256 каталога Microsoft, SDK — с SHA-512 метаданных NuGet. Проверки целостности не отключались.
