## Изменения

- «Офлайн-набор» показывает программы без предварительного выбора в каталоге. Добавлены поиск, выбор всех поддерживаемых пакетов, сброс и причины недоступности остальных программ. Доступны автономные снимки Python 3.12.10, Git 2.49.0 и VS Code 1.99.3 для Windows x64. Подготовленный набор содержит полные EXE, манифест, SHA-256 и инструкцию; локальная установка проходит через просмотр и подтверждение плана.
- Результат установки отделён от проверки готовности. Для Python, Git и VS Code добавлены повторная проверка и открытие программы, когда готовность и способ запуска подтверждены. Ошибки содержат понятное объяснение и дальнейшие действия; подробный журнал доступен отдельно.
- Добавлен перенос безопасных настроек VS Code, Git и Windows Terminal: предпросмотр, выбор компонентов, обработка конфликтов, резервная копия и восстановление.
- Прямые загрузки сохраняют частичные файлы и проверяют возможность продолжения после перезапуска. Для активных загрузок доступны пауза, продолжение и отмена, включая скачивание перед установкой через WinGet.
- Добавлены трей, расписание проверки обновлений, уведомления, настройки автозапуска, предотвращения сна и ограничения скорости. Установки по расписанию не запускаются.
- Реализована проверка подписанных обновлений каталога с откатом повреждённых данных. Адрес публикации и ключ production-источника пока не настроены; используется встроенный каталог.

## Проверка и ограничения

Проверены каталог из 83 продуктов, 81 тест TypeScript, 60 тестов Rust, production-сборка, форматирование и сквозные сценарии интерфейса. Три opt-in проверки Rust пропущены в обычном прогоне. Сценарий офлайн-выбора начинается с пустого общего выбора и проверяет поиск, состав результата, блокировку неподготовленных действий и обе темы при ширине 1020 пикселей.

Демонстрационный режим не скачивает установщики и не выдаёт виртуальный набор за проверенный. Нативная проверка функций отдельно подтверждала скачивание Python по HTTPS, доверенный SHA-256, отклонение повреждённой копии и подготовку локального плана без запуска установщика. Полная установка на чистом компьютере без сети и полный цикл системных уведомлений / автозапуска / сна не входят в подтверждённые сценарии.

Для запуска нужны Windows 11 x64 и WebView2. Сертификат подписи EXE не настроен. Подробности: [функции](FEATURES-2026-11-09.md), [проверки](VALIDATION.md), [ограничения](LIMITATIONS.md).
