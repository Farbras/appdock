# AppDock

Версия **0.2.3** исправляет пустой список в «Офлайн-наборе»: программы выбираются прямо в разделе, доступны поиск, массовый выбор и причины недоступности остальных пакетов. В выпуск включены проверка готовности, понятные ошибки, перенос безопасных настроек, трей и расписание, восстановление прямых загрузок и механизм подписанного обновления каталога. Подробности: [изменения 0.2.3](docs/APPDOCK-0.2.3.md), [инструкции по функциям](docs/FEATURES-2026-11-09.md). Production-источник каталога и ключ требуют настройки.

В каталоге доступны Office 2024, 2021, 2019 и 2016 с прямым скачиванием образов Microsoft. В очереди видны процент, скачанный и оставшийся объём, скорость и оценка времени до завершения. Готовые файлы AppDock доступны в GitHub Releases.

Настольное приложение для Windows 11: каталог программ, параметры, итоговый план, последовательная установка через WinGet, отдельные загрузки и отчёт. Интерфейс полностью на русском языке. В каталоге 83 отдельных продукта; 40 основных WinGet-интеграций, 3 редакции Visual Studio и 8 расширений VS Code проверены по источникам.

В очереди для всех загрузок через AppDock отображаются процент, скачанный и оставшийся объём, текущая скорость и оценка времени до завершения. Показатели доступны как для действия «Только скачать», так и при скачивании перед установкой через WinGet. При неизвестном размере процент, оставшийся объём и время остаются неопределёнными; время рассчитывается после получения размера и скорости. Загрузки в браузере и внутри отдельных мастеров производителей AppDock не отслеживает.

У каждой активной загрузки доступны кнопки «Пауза», «Продолжить» и «Отменить». WinGet приостанавливает свой активный процесс; прямые загрузки сохраняют байты и поддерживают проверяемое продолжение после перезапуска. Общие кнопки управляют текущими загрузками и ожидающими задачами. Уже запущенная установка завершается штатно. Правила восстановления и удаления частей описаны в документации доработок.

В категории «Документы и таблицы» доступны Office 2024, 2021, 2019 и 2016. Действие «Только скачать» автоматически сохраняет образ по прямой ссылке Microsoft в выбранную папку загрузок. После скачивания образ нужно открыть и запустить `setup.exe`.

## Скачать AppDock 0.2.3 для Windows

**[Скачать установщик AppDock для Windows x64](https://github.com/Farbras/appdock/releases/download/v0.2.3/AppDock_0.2.3_x64-setup.exe)**

Для запуска без установки скачайте **[ZIP с готовым AppDock.exe](https://github.com/Farbras/appdock/releases/download/v0.2.3/AppDock-0.2.3-windows-x64.zip)**, распакуйте архив в отдельную папку и откройте `AppDock.exe`. Также доступен [отдельный AppDock.exe](https://github.com/Farbras/appdock/releases/download/v0.2.3/AppDock.exe).

Готовая версия рассчитана на Windows 11 x64. Для отображения интерфейса нужен Microsoft Edge WebView2 Runtime; установщик скачает его при отсутствии. Для установки программ из каталога нужен WinGet / App Installer и доступ в интернет. Node.js, Rust и инструменты сборки для запуска готовой программы не нужны.

Все файлы выпуска: **[GitHub Releases](https://github.com/Farbras/appdock/releases/latest)**. Кнопка GitHub «Code → Download ZIP» скачивает исходный код; готовый ZIP с `.exe` находится в Releases по ссылке выше.

## Запуск из исходного кода

Требования обычной среды разработки: Node.js 22+, npm, стабильный Rust MSVC, Microsoft C++ Build Tools с Windows SDK, WebView2. Для реальных пакетных операций нужен WinGet / App Installer.

```powershell
npm ci
npm run desktop
```

В текущей рабочей папке есть локальный npm и скрипт настройки портативных инструментов; глобальный PATH менять не требуется:

```powershell
.\scripts\npm.ps1 run dev       # браузерный деморежим, http://127.0.0.1:1420
.\scripts\desktop.ps1          # нативное окно Tauri
.\scripts\desktop.ps1 -Build   # сборка NSIS
```

В браузере всегда включена явная демонстрация. Нативное приложение по умолчанию работает с реальным компьютером; переключатель деморежима находится в настройках. Первый запуск очереди требует просмотра конкретного плана и подтверждения внутри приложения. Каталог автоматически не выбирается.

## Сборка Windows

```powershell
npm run bundle
```

Результаты стандартной сборки: `src-tauri/target/release/appdock.exe` и `src-tauri/target/release/bundle/nsis/AppDock_0.2.3_x64-setup.exe`. NSIS устанавливает AppDock для текущего пользователя; приложение не требует запуска целиком от администратора. Пакетные установщики запрашивают собственный UAC. Сертификат подписи выпуска не настроен.

После сборки `python scripts/package-release.py` подготовит в `releases/AppDock-0.2.3/` установщик, отдельный `.exe`, ZIP для запуска без установки, архив исходников и файл SHA-256. Для этого шага нужен Python 3.

Если нет системных Build Tools, `scripts/build-env.ps1` умеет использовать уже подготовленные инструменты из `.tools`. Их архивы получены с серверов Microsoft, проверены по SHA-256 каталога Microsoft / SHA-512 метаданных NuGet и распакованы локально. Разработка не требует повторной установки Visual Studio или изменения её компонентов.

## Проверки

```powershell
npm run check
cargo test --manifest-path src-tauri/Cargo.toml
cargo fmt --manifest-path src-tauri/Cargo.toml -- --check
```

Для портативной среды перед Cargo выполните `. .\scripts\build-env.ps1`. Сквозной UI-сценарий: `node scripts/ui-smoke.mjs` с зависимостями проекта (`playwright`) и Edge. Playwright включён в devDependencies; установка программ не выполняется. Тесты не устанавливают программы из каталога.

## Данные и расширение каталога

- `catalog/apps.json` — отдельные продукты, типы, платформы, условия, источники и правила обнаружения.
- `catalog/extensions.json` — точные Marketplace ID и зависимости.
- `catalog/presets.json` — 9 стартовых наборов без конкурирующих браузеров и офисных пакетов.
- `catalog/vs-profiles.json`, `catalog/vsconfig/` — снимок состава Visual Studio для трёх редакций.
- `docs/integration-checks.json` — исходные ответы проверки пакетов и Marketplace.

Новый продукт добавляется отдельным манифестом-записью в `catalog/apps.json`. Для безопасной установки нужно указать точный ID источника WinGet, разрешённые параметры и правила обнаружения, затем выполнить `node scripts/verify-integrations.mjs`, `npm run check` и пересобрать нативную часть. Отметка `verified` без успешной проверки источника не допускается. Наборы JSON не могут добавлять команды или новые установочные источники.

Импорт и экспорт наборов доступны на экране «Наборы». Данные содержат программы, версии, действия и разрешённые параметры. Пароли вводятся только в официальном мастере производителя и не попадают в AppDock.
